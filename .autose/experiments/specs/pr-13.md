## Goal
Let `count()` be called without a query so that it returns the number of all documents in the table.

## Current behaviour
`Table.count(cond)` requires a query. Calling `table.count()` raises a TypeError.

## Requirements
- FR-1: `count()` with no argument returns the number of documents in the table.
- FR-2: `count(cond)` with a query behaves exactly as before.

## Acceptance criteria
- **AC-1** (FR-1) [CONFIRMED]: Given a table with 3 documents, when `count()` is called with no argument, then it returns 3.
- **AC-2** (FR-1) [INFERRED]: Given a database whose default table has 2 documents, when `db.count()` is called, then it returns 2.
- **AC-3** (FR-1) [INFERRED]: Given an empty table, when `count()` is called, then it returns 0.
- **AC-4** (FR-2) [CONFIRMED]: Given a table with 2 documents of kind 'a', when `count(where('kind') == 'a')` is called, then it returns 2.

## Assumptions
- [INFERRED] `count()` with no argument should equal `len(table)`.

## Open questions
- None.

## Out of scope
- Changing `len()`.
